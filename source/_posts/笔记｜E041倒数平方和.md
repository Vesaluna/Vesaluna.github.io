今天读了欧拉的 E041『De summis serierum reciprocarum』中的前半部分，很有意思，要求的数学知识并不多，但从拉丁语原文翻译过来的英语诘屈聱牙、生涩难懂。

下为笔记：

{% mathjax %}
1+\frac{1}{2^2}+\frac{1}{3^2}+\frac{1}{4^2}+\cdots.
{% endmathjax %}

设圆的半径 {% mathjax %}BC=1{% endmathjax %}，弧 {% mathjax %}AM=s{% endmathjax %}，{% mathjax %}PM=y{% endmathjax %}，{% mathjax %}PC=x{% endmathjax %}。图中先取 {% mathjax %}0<s<\pi/2{% endmathjax %}，于是 {% mathjax %}PM{% endmathjax %} 是弧 {% mathjax %}AM{% endmathjax %} 的正弦，{% mathjax %}PC{% endmathjax %} 是余弦。

![单位圆中，弧 AM 的正弦为 PM，余弦为 PC](/images/euler-e041-circle.svg)

由 Taylor 公式可知，

{% mathjax %}
y=s-\frac{s^3}{3!}+\frac{s^5}{5!}-\frac{s^7}{7!}+\cdots,
{% endmathjax %}

{% mathjax %}
x=1-\frac{s^2}{2!}+\frac{s^4}{4!}-\frac{s^6}{6!}+\cdots.
{% endmathjax %}

下面只用正弦的式子

一般是给定 {% mathjax %}s{% endmathjax %} 求 {% mathjax %}y{% endmathjax %}，这里反过来寻找使正弦等于 {% mathjax %}y{% endmathjax %} 的所有弧长。这样的 {% mathjax %}s{% endmathjax %} 不止一个。

先把等式移到一边，再除以 {% mathjax %}y{% endmathjax %}，使常数项成为 {% mathjax %}1{% endmathjax %}：

{% mathjax %}
0=y-s+\frac{s^3}{3!}-\frac{s^5}{5!}+\cdots,
{% endmathjax %}

{% mathjax %}
0=1-\frac{s}{y}+\frac{s^3}{3!y}-\frac{s^5}{5!y}+\cdots.
{% endmathjax %}

把右边看成关于 {% mathjax %}s{% endmathjax %} 的无穷次式，记所有根为 {% mathjax %}A,B,C,D,\ldots{% endmathjax %}。

则仿照有限次多项式，「可以」（一般来说不能这么做）分解为一次因子的乘积，即

{% mathjax %}
1-\frac{s}{y}+\frac{s^3}{3!y}-\cdots
=\left(1-\frac{s}{A}\right)
 \left(1-\frac{s}{B}\right)
 \left(1-\frac{s}{C}\right)\cdots.
{% endmathjax %}

再记 {% mathjax %}a=1/A{% endmathjax %}、{% mathjax %}b=1/B{% endmathjax %}、{% mathjax %}c=1/C{% endmathjax %}，依此类推。先把前几个因子展开，以观察规律。两个因子相乘时，

{% mathjax %}
(1-as)(1-bs)=1-(a+b)s+abs^2.
{% endmathjax %}

三个因子时的情况为

{% mathjax %}
(1-as)(1-bs)(1-cs)
=1-(a+b+c)s+(ab+ac+bc)s^2-abcs^3.
{% endmathjax %}

可知 {% mathjax %}s{% endmathjax %} 项的系数为 {% mathjax %}-(a+b+c+\cdots){% endmathjax %}；{% mathjax %}s^2{% endmathjax %} 项的系数是 {% mathjax %}\sum_{i<j}a_i a_j{% endmathjax %}，即从不同的数中取两个相乘再求和；{% mathjax %}s^3{% endmathjax %} 项的系数是 {% mathjax %}-\sum_{i<j<k}a_i a_j a_k{% endmathjax %}，要从不同的数中取三个，且前面有负号。

记

{% mathjax %}
\alpha=a+b+c+\cdots=\frac1y,
{% endmathjax %}

{% mathjax %}
\beta=ab+ac+bc+\cdots=0,
{% endmathjax %}

{% mathjax %}
\gamma=abc+abd+acd+\cdots=-\frac1{3!y}.
{% endmathjax %}

左边 {% mathjax %}s{% endmathjax %} 的系数是 {% mathjax %}-1/y{% endmathjax %}，右边是 {% mathjax %}-\alpha{% endmathjax %}；左边没有 {% mathjax %}s^2{% endmathjax %} 项，所以 {% mathjax %}\beta=0{% endmathjax %}。{% mathjax %}s^3{% endmathjax %} 项右边为 {% mathjax %}-\gamma{% endmathjax %}，左边为 {% mathjax %}1/(3!y){% endmathjax %}，故 {% mathjax %}\gamma=-1/(3!y){% endmathjax %}。

先展开 {% mathjax %}\alpha{% endmathjax %} 的平方

{% mathjax %}
(a+b+c+\cdots)^2
=a^2+b^2+c^2+\cdots+2(ab+ac+bc+\cdots),
{% endmathjax %}

因此

{% mathjax %}
Q:=a^2+b^2+c^2+\cdots=\alpha^2-2\beta=\frac1{y^2}.
{% endmathjax %}

记 {% mathjax %}R=a^3+b^3+c^3+\cdots{% endmathjax %}

则有

{% mathjax %}
R:=a^3+b^3+c^3+\cdots
=\alpha^3-3\alpha\beta+3\gamma
=\frac1{y^3}-\frac1{2y}.
{% endmathjax %}

求倒数平方和只需要 {% mathjax %}Q{% endmathjax %}

令 {% mathjax %}A{% endmathjax %} 为正弦等于 {% mathjax %}y{% endmathjax %} 的最小正弧长，半圆的弧长记为 {% mathjax %}p=\pi{% endmathjax %}。在一个周期内，{% mathjax %}A{% endmathjax %} 与 {% mathjax %}p-A{% endmathjax %} 的正弦相同，加上或减去整周 {% mathjax %}2p{% endmathjax %} 后，正弦也不变。故根分成两列：

{% mathjax %}
s=A+2kp
\quad\text{或}\quad
s=p-A+2kp,
\qquad k\in\mathbb Z.
{% endmathjax %}

例如按 {% mathjax %}0, -1, 1, -2, 2, \cdots{% endmathjax %} 由此外取，则前面几项可列成 {% mathjax %}A{% endmathjax %}、{% mathjax %}p-A{% endmathjax %}、{% mathjax %}-p-A{% endmathjax %}、{% mathjax %}2p+A{% endmathjax %}、{% mathjax %}-2p+A{% endmathjax %}……

现在观察 {% mathjax %}y=1{% endmathjax %} 这种特殊情况

则 {% mathjax %}A=\pi/2{% endmathjax %}，而 {% mathjax %}p-A=\pi/2{% endmathjax %}

所以 {% mathjax %}\pi/2{% endmathjax %}、{% mathjax %}-3\pi/2{% endmathjax %}、{% mathjax %}5\pi/2{% endmathjax %}……，每个都须计算两次

前面算得 {% mathjax %}Q=1/y^2{% endmathjax %}，此时 {% mathjax %}Q=1{% endmathjax %}

{% mathjax %}
1=2\left(
\frac1{(\pi/2)^2}
+\frac1{(3\pi/2)^2}
+\frac1{(5\pi/2)^2}
+\cdots\right).
{% endmathjax %}

{% mathjax %}(\pi/2)^{-2}=4/\pi^2{% endmathjax %} 提出，得

{% mathjax %}
1=\frac8{\pi^2}\left(1+\frac1{3^2}+\frac1{5^2}+\cdots\right).
{% endmathjax %}

因此，

{% mathjax %}
1+\frac1{3^2}+\frac1{5^2}+\cdots=\frac{\pi^2}{8}.
{% endmathjax %}

也就是倒数平方和中的奇数项。

令 {% mathjax %}S=\sum_{n=1}^{\infty}1/n^2{% endmathjax %}

偶数项可写为

{% mathjax %}
\frac1{2^2}+\frac1{4^2}+\frac1{6^2}+\cdots
=\frac14\left(1+\frac1{2^2}+\frac1{3^2}+\cdots\right)
=\frac14S.
{% endmathjax %}

所以奇数项之和为 {% mathjax %}S-S/4{% endmathjax %}，继而得

{% mathjax %}
\frac34S=\frac{\pi^2}{8},
\qquad S=\frac{\pi^2}{6}.
{% endmathjax %}

原文：[Leonhard Euler, *De summis serierum reciprocarum*（E041）](https://scholarlycommons.pacific.edu/euler-works/41/)。
