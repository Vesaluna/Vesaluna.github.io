有些积分直接计算不太方便，添入一个参数，反而容易着手。我当时把它记作「积分因子法」，但这里用的其实是对含参数的积分求导，并非微分方程中的积分因子。

先看

{% mathjax %}
\int_0^{\infty}\frac{\sin x}{x}\,dx.
{% endmathjax %}

在被积函数中添入 {% mathjax %}e^{-tx}{% endmathjax %}，暂且令 {% mathjax %}t>0{% endmathjax %}，记

{% mathjax %}
\varphi(t)=\int_0^{\infty}e^{-tx}\frac{\sin x}{x}\,dx.
{% endmathjax %}

这里不能只凭「微分与积分可以交换」一句话就把导数放进积分号；原笔记在这里写了一段未完成的定理。对 {% mathjax %}t>0{% endmathjax %}，若把 {% mathjax %}t{% endmathjax %} 限制在一个不触及零的闭区间内，指数因子给出足够的衰减，可以用求导法则处理。对 {% mathjax %}t{% endmathjax %} 求导时，{% mathjax %}e^{-tx}{% endmathjax %} 会多出一个 {% mathjax %}-x{% endmathjax %}，恰好约掉分母的 {% mathjax %}x{% endmathjax %}：

{% mathjax %}
\varphi'(t)
=-\int_0^{\infty}e^{-tx}\sin x\,dx
=-\frac{1}{1+t^2}.
{% endmathjax %}

于是 {% mathjax %}\varphi(t)=\operatorname{arccot}(t)+C{% endmathjax %}。由于 {% mathjax %}t\to\infty{% endmathjax %} 时积分趋于零，而 {% mathjax %}\operatorname{arccot}(t){% endmathjax %} 也趋于零，所以 {% mathjax %}C=0{% endmathjax %}。让 {% mathjax %}t\downarrow0{% endmathjax %}，便得到

{% mathjax %}
\int_0^{\infty}\frac{\sin x}{x}\,dx=\frac{\pi}{2}.
{% endmathjax %}

最后一步是取极限，不是直接把 {% mathjax %}t=0{% endmathjax %} 代入一个只对 {% mathjax %}t>0{% endmathjax %} 证明过的求导公式；它还需要对这个振荡积分的收敛作出说明。这是原笔记里跳得太快的一处。

同样的想法也让我想到欧拉关于阶乘的积分。对 {% mathjax %}t>0{% endmathjax %}，先有

{% mathjax %}
\int_0^{\infty}e^{-tx}\,dx=\frac1t.
{% endmathjax %}

两边对 {% mathjax %}t{% endmathjax %} 求 {% mathjax %}n{% endmathjax %} 次导数，每次被积函数都多出一个 {% mathjax %}-x{% endmathjax %}，所以

{% mathjax %}
(-1)^n\int_0^{\infty}x^ne^{-tx}\,dx
=\frac{(-1)^nn!}{t^{n+1}},
{% endmathjax %}

也就是

{% mathjax %}
\int_0^{\infty}x^ne^{-tx}\,dx=\frac{n!}{t^{n+1}}.
{% endmathjax %}

取 {% mathjax %}t=1{% endmathjax %}，得到 {% mathjax %}\int_0^{\infty}x^ne^{-x}\,dx=n!{% endmathjax %}。原笔记把分母写作 {% mathjax %}t^n{% endmathjax %}，这里改正为 {% mathjax %}t^{n+1}{% endmathjax %}。同样，交换求导和无穷区间上的积分，需要在 {% mathjax %}t>0{% endmathjax %} 的邻域中找一个可积的上界；只说函数在某个区间上一致连续并不足够。
